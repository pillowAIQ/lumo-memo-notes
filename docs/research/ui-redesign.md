# 备忘录界面升级：产品调研与设计说明

调研及实现日期：2026-11-13。

## 1. 调研结论

本项目是 Windows / PySide6 的本地备忘录，不是文档协作平台。
适合借鉴成熟产品的信息层级和视觉规律，不应为模仿而引入复杂编辑器、
云同步、登录页或没有实际功能的装饰按钮。

| 参考产品 | 官方资料 | 借鉴的设计原则 | 本次落地 |
| --- | --- | --- | --- |
| Apple Notes | [整理备忘录](https://support.apple.com/guide/iphone/organize-in-folders-ipha61270292/ios) | 导航和内容明确分区；置顶易于查找 | 独立侧栏、页面标题、置顶筛选 |
| Bear | [侧栏说明](https://bear.app/faq/about-the-sidebar-in-bear/) / [图标更新](https://blog.bear.app/2026/03/bear-2-7-a-fresh-look-for-tagcons/) | 分类可扫读，图标笔画与尺度一致 | 文件夹线性图标、分类数量、统一 SVG 控件图标 |
| flomo | [设计哲学](https://help.flomoapp.com/about-us/about-us/design-concept.html) | 少颜色、低压力输入、安静的内容容器 | 顶部轻量输入、回车保存、克制的绿色强调 |
| Craft | [产品官网](https://www.craft.do/) / [每日笔记](https://support.craft.do/en/plan-and-do/daily-notes) | 标题、正文、辅助信息有明确的阅读节奏 | 标题区、输入区、筛选区、记录区的间距层级 |

补充实地查看了 Bear 和 Craft 官方网站；参考的是工作区的信息结构，
而非复制官网营销页，也不使用它们的品牌、插画或专有资源。

## 2. 视觉方向：暖纸与松绿

- 背景：纸白 `#FAFBF8`，内容区域使用非常轻的双色渐变。
- 侧栏：淡灰绿 `#F1F3ED`；选中底色 `#DEE8DB`。
- 主文字：深松绿 `#283D35`；辅助文字：`#69766E`。
- 主操作：松绿 `#2D6550`；紧急信息才使用陶土色。
- 字体：中文使用本机微软雅黑 UI；英文 `memo` 字标使用 Georgia。
- 文字层级：页面标题 24px（紧凑窗口 22px），记录正文 14px，元信息 11px。
- 图标：统一 24 单位画布、1.6 单位圆头线条，内置 SVG，无网络依赖。
- 不引入闪烁、循环动画或大面积玻璃效果，保持桌面工具的安静与即时响应。

主题集中在 `src/memo_app/theme.py`，图标集中在 `src/memo_app/icons.py`。
应用不依赖下载字体或外部图片。

## 3. 交互与兼容范围

- 保留 PySide6、SQLite、全局快捷记录、托盘、提醒及原有数据结构。
- 保留“普通记录完成即进入回收站、恢复后回到待办”的现有行为。
- 搜索常驻，支持 Ctrl+F 聚焦、Esc 清空。
- 筛选只使用已有真实数据：全部、已置顶、有提醒。
- 输入说明移到辅助行；高级输入语法放在提示中，不再挤满占位文字。
- 新增可点击的记录按钮；回车仍然保存；双击编辑、右键菜单不变。
- 从主输入新增记录时清除搜索和快捷筛选，让新记录立即可见。
- 分类可键盘选择，按钮有焦点反馈，图标按钮有名称和提示。
- 分类聚焦时显示删除入口，Delete 键同样进入原有确认流程。
- 分类过多时侧栏独立滚动；分类长名称省略显示并提供完整提示。
- 卡片内容和分类按纯文本显示；正文、分类、提醒分别分配空间。
- 快捷记录、桌面挂件、分类窗口、任务属性、设置共享同一视觉方向。
- 默认主窗口为 1080×800；保留 680×520 最小窗口并采用紧凑边距。
- 标题与搜索合并为一行，优先给记录留出空间；紧凑窗口隐藏副标题、
  侧栏标语及隐私说明卡，但保留底部本地存储状态。
- 下拉框与日期选择器使用统一 SVG 箭头；挂件的任务正文在前，
  截止、优先级等信息单独放在下一行。
- 桌面挂件按使用反馈恢复原有深色半透明背景（alpha 190/255），
  文字及线性图标改用明亮的灰绿配色，主窗口最小化后仍能透出桌面；
  只调整背景绘制透明度，不降低整窗及文字的不透明度。
- 主界面与挂件自动互斥：主界面显示时隐藏挂件，最小化或关闭到托盘后显示。
  自动隐藏不更改托盘中的启用状态；通过 × 手动隐藏后，需在托盘重新启用。
- 挂件右上角原“打开主界面”按钮改为最小化按钮，收起为标题及数量小条，
  原位按钮可恢复列表，数据刷新和主窗口切换均保留收起状态。
  双击挂件空白处仍可打开主界面。

这是原生桌面项目，不增加没有客户端支持的“手机网页适配”。

## 4. 验证方法

执行：

```bash
.venv/Scripts/python.exe ui_smoke.py
```

脚本使用独立临时数据库，不读取或修改真实备忘录，不注册全局热键，
不改写用户设置。验证新增、编辑保存/取消、搜索、筛选、分类归属、
完成/恢复、回收站、长文本、多分类和小窗口布局，并生成主界面、
空状态、快捷输入、挂件及对话框的复现截图。
同时使用真实 Controller 事件连线检查主界面/挂件自动切换、托盘启用状态、
挂件最小化/还原及分组状态保留；系统托盘、热键监听和设置读取使用测试替身，
不会在实际桌面注册托盘图标或全局快捷键。

截图位于 `audit_shots/redesign/`，沿用项目现有截图目录的忽略策略。
Windows 的 Qt offscreen 插件不自动发现系统字体，脚本仅在测试进程中
显式加载本机中文字体，避免原有截图中中文变方框的问题。
同时在 Windows 原生窗口后端执行相同检查，覆盖本机 150% 显示缩放；
原生截图位于 `audit_shots/redesign_native/`。

打包精简脚本同步保留 `Qt6Svg.dll`，避免线性图标在打包后缺少运行库。

辅助检查：

```bash
.venv/Scripts/python.exe -m compileall -q src/memo_app ui_smoke.py
git diff --check
```

审美评分由新的独立审查 agent 根据实际截图给出，是设计评估，
不是客观行业认证；同时检查代码风险和需求是否正确收敛。
