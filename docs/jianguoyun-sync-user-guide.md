# 坚果云同步 — 用户指南

多设备同步：在多台 Windows 电脑上用同一个坚果云账号 + 同一个远程目录
+ 同一个"同步库密码"，备忘录/分类/任务属性自动双向同步。
数据端到端加密，坚果云服务器看不到内容。

## 一、前置准备

1. 注册/登录坚果云账号（https://www.jianguoyun.com）
2. 生成**第三方应用密码**（不是登录密码！）：
   坚果云官网 → 账户信息 → 安全选项 → 第三方应用密码 → 生成（勾选 WebDAV）
3. 想一个**同步库密码**：这是加密密钥，多台设备必须相同，**忘记无法找回**

## 二、设置（仿 Obsidian Sync 的三段式）

打开轻笺 · Lumo → 侧栏左下角「设置」→「多端同步」，在主窗口内的设置页完成配置：

### 备份提醒

同步会修改/删除本地数据，建议先备份重要文件。

### 账号

- 勾选"启用多设备同步"
- 填**服务器地址**（默认 `https://dav.jianguoyun.com/dav/`，一般不用改）
- 填**账号**（坚果云登录邮箱）+ **应用密码**
- 点 **「登录并保存」** → 验证成功后立即安全保存账号；登录后可点「检查连接」再次验证
- 登录成功后收起地址、账号、密码输入框，仅显示"已登录：xxx"、连接检查和「退出登录」按钮——
  **凭据存在 Windows 凭据管理器，之后不需要重复登录**

### 通用

- **远程目录**：数据存放的坚果云文件夹，点「浏览…」可以像
  Obsidian 一样逐级选择目录。默认 `memo-app` 尚不存在时会从根目录开始浏览；也可直接输入 `/memo-app`，初始化时自动创建。`/` 表示根目录
- 目录在后台读取，打开窗口和取消操作不会等待网络。返回上级、重复打开可复用 60 秒内的目录缓存；点击「刷新」强制重新读取。
- 单击选中文件夹后点「选择目录」即可使用；双击可进入文件夹。
- 点「新建文件夹」可在当前位置创建文件夹，成功后自动选中；失败时可重试。
- 坚果云优先使用直连，连接失败时回退到系统代理；其他 WebDAV 地址沿用系统代理设置。
- **同步库密码**：自定义加密密码（≥6 位，多设备必须相同）
- 点 **「初始化同步库」**：
  - 远程目录里已有同步库 → 自动加入（不需要输库 ID）
  - 远程目录是空的 → 自动创建新库
  - 成功后显示绑定的远程目录；数据直接出现在你选的坚果云文件夹里，
    可以在坚果云客户端/网页端亲眼看到
- **冲突解决策略**：后写覆盖（默认）/ 保留冲突副本

### 同步状态

底部实时显示上次同步结果。

> 你的全部历史备忘录会在首次同步时自动上传（bootstrap）。

## 三、其他设备加入

1. 新设备安装轻笺 · Lumo → 设置 → 多端同步
2. 填**相同账号 + 应用密码** → 「登录并保存」✓
3. **远程目录选完全相同的目录**（用「浏览…」选到同一个文件夹）
4. 填**相同的同步库密码** → 「初始化同步库」→ 自动识别并加入
5. 稍等即自动拉取全部数据

> 不需要记库 ID——同步库身份存在远程目录的 `vault.json` 里，
> 选对目录 + 对密码就能加入。

## 四、日常使用

- **自动同步**：编辑备忘录后约 20 秒自动上传；每 2 分钟自动拉取一次
- **手动同步**：标题栏「同步」按钮 → 状态菜单 →「立即同步…」
  会先选择冲突策略：
  - **接受后写覆盖**：同一条备忘录两端同时改 → 修订时间晚的一方胜出
  - **保留冲突副本**：落败版本另存为 `【冲突副本】` 前缀的本地备忘录，
    不参与同步回传；该选择只影响本次手动同步，自动同步始终 LWW
- **状态查看**：标题栏同步按钮颜色（灰=未启用/橙=同步中/绿=已同步/红=失败，
  悬停看详情）+ 设置底部状态栏
- **离线可用**：断网时一切照常本地使用，恢复后自动补同步

## 五、常见问题

| 现象 | 原因/处理 |
|---|---|
| 状态显示"同步失败：401/403" | 应用密码错误或过期 → 重新生成后更新 |
| "同步失败：认证失败/解密" | 同步库密码不一致 → 多设备必须用同一个库密码 |
| "远程目录不是当前绑定的同步库" | 远程目录指到了另一个同步库 → 改回绑定时的目录 |
| "远端不是有效的同步库" | 该目录的 vault.json 缺 vault_id（旧版库）或已损坏 |
| "安全存储不可用" | Windows 凭据管理器异常，重启电脑或检查系统策略 |
| 第二台设备拉不到数据 | 确认远程目录相同 + 同一个库密码 |
| 忘记库密码 | **无法找回**，加密数据永久不可读；只能换目录重新开始 |

## 六、安全说明

- 备忘内容端到端加密（AES-256-GCM），坚果云只存密文
- 账号/应用密码/库密码存 Windows 凭据管理器，不写入任何文件
- 每台设备有独立 writer_id，删除有墓碑机制不会复活
- 同步库密码 = 唯一解密途径，请抄写保管
- 远程目录可放在坚果云任意位置（含根目录），程序不会动目录里
  已有的其他文件
