# 坚果云同步 — 用户指南

多设备同步：在两台 Windows 电脑上用同一个坚果云账号 + 同一个"同步库"，
备忘录/分类/任务属性自动双向同步。数据端到端加密，坚果云服务器看不到内容。

## 一、前置准备

1. 注册/登录坚果云账号（https://www.jianguoyun.com）
2. 生成**第三方应用密码**（不是登录密码！）：
   坚果云官网 → 账户信息 → 安全选项 → 第三方应用密码 → 生成（勾选 WebDAV）
3. 想一个**同步库密码**：这是加密密钥，两台设备必须相同，**忘记无法找回**

## 二、第一台设备（新建同步库）

1. 打开 memo → 托盘图标右键 → **设置…**
2. 勾选"启用多设备同步"
3. 填写：
   - 服务器地址：默认 `https://dav.jianguoyun.com/dav/`（不用改）
   - 账号：坚果云登录邮箱
   - 应用密码：刚生成的第三方应用密码
   - 同步库密码：自定义的加密密码（≥6 位）
4. "新建同步库"保持选中 → **保存**
5. 稍等片刻，状态显示"同步库已就绪"即成功

> 你的全部历史备忘录会在首次同步时自动上传（bootstrap）。

## 三、第二台设备（加入已有同步库）

1. 在**第一台设备**的设置里，"加入已有同步库"下方会显示同步库 ID
   （也可以在第一台设备的同步库目录 `memo-sync/<ID>/` 中找到）
2. 第二台设备打开设置：
   - 勾选"启用多设备同步"
   - 填相同的账号 + 应用密码
   - 选"加入已有同步库"，粘贴**同步库 ID**
   - 填**相同的同步库密码**
3. 保存 → 状态"同步库已就绪" → 自动拉取第一台设备的全部数据

## 四、日常使用

- **自动同步**：编辑备忘录后约 20 秒自动上传；每 2 分钟自动拉取一次
- **手动同步**：设置 → "立即同步"按钮
- **状态查看**：设置对话框底部实时显示上次同步结果
- **离线可用**：断网时一切照常本地使用，恢复后自动补同步
- **冲突规则**：同一条备忘录两端同时改 → 以后同步的一方覆盖（后写覆盖）

## 五、常见问题

| 现象 | 原因/处理 |
|---|---|
| 状态显示"同步失败：401/403" | 应用密码错误或过期 → 重新生成后在设置里更新 |
| "同步失败：认证失败/解密" | 同步库密码不一致 → 两台设备必须用同一个库密码 |
| "安全存储不可用" | Windows 凭据管理器异常，重启电脑或检查系统策略 |
| 第二台设备拉不到数据 | 确认用了同一个同步库 ID + 同一个库密码 |
| 忘记库密码 | **无法找回**，加密数据永久不可读；只能删除同步库重新开始 |

## 六、安全说明

- 备忘内容端到端加密（AES-256-GCM），坚果云只存密文
- 账号密码存 Windows 凭据管理器，不写入任何文件
- 每台设备有独立 writer_id，删除有墓碑机制不会复活
- 同步库密码 = 唯一解密途径，请抄写保管
